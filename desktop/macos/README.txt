PATRIMONY — DESKTOP APPLICATION (macOS)
=======================================

🌍 Other languages: Français → LISEZ-MOI.txt · Deutsch → LIESMICH.txt ·
   Lëtzebuergesch → LIES-MICH.txt

Your wealth, your data, on YOUR computer.
No server, no online account, no connection required
(except crypto prices, which come from public sources).

INSTALLATION (2 minutes, no installer)
--------------------------------------
1. Unzip « Patrimony-macOS.zip » wherever you like (Documents, for
   example). Keep everything as-is: your data will live next to the
   application.
2. Double-click « Patrimony.app ».

   First launch: macOS may say "macOS cannot verify the developer of
   this application" (normal for an unsigned application). Right-click
   « Patrimony.app » → « Open », then confirm « Open ». Afterwards, a
   double-click is enough.

3. The Patrimony window opens.

FIRST LOGIN
-----------
   Username: admin
   Password: change-me

   ⚠️ Change it right away: « Settings » menu once logged in.

YOUR DATA
---------
It lives in the « data » folder, next to Patrimony.app.
Backup = copy that « data » folder to a USB stick or an external drive
from time to time. Nothing is sent over the Internet: tracked crypto
addresses are queried through public explorers (read-only), never your
private keys.
Tip: if you move Patrimony.app, take the « data » folder with it —
they belong together.

TO CLOSE
--------
Close the window (the red button). The software stops — nothing keeps
running in the background.

TROUBLESHOOTING
---------------
- "macOS cannot verify the developer": that's step 2 (right-click →
  Open). Only once.
- The window does not open: launch the application again. If the
  problem persists, the « error.log » file next to the application
  contains details to send to the developer.
- The « data » folder does not appear next to the application
  (protected location): Finder → « Go » menu → « Go to Folder… » →
  ~/Library/Application Support/Patrimony
- Reset (erase everything): delete the « data » folder; everything
  starts from scratch on the next launch.
- Update: download the new archive and replace « Patrimony.app »
  (keep your « data » folder).
